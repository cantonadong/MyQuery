# SQL Desk Implementation Plan

Goal: Independent Windows SQL client using Rust + Slint, leaving MyBI intact.
Architecture: Declarative Slint widgets; one bounded background command queue and persistent PostgreSQL-protocol session for PostgreSQL/Redshift. Disk-backed result sets with 100-row pages; streaming CSV export. TLS certificate verification by default; Windows Credential Manager stores passwords.
Constraints: No tests executed, as explicitly required by user. No feature branches; current folder has no Git metadata. No server credentials available. Do not change existing MyBI files.

- [x] Create `sql-desk/ui/main.slint`: connection configuration, lazy object browser, SQL editor, result sets/table, paging, status/error details, Chinese/English.
- [x] Create `sql-desk/src/config.rs`: bounded saved profiles, atomic configuration writes, Windows credentials.
- [x] Create `sql-desk/src/results.rs`: temporary JSON-lines result storage, page offsets, full CSV export and bounded page clipboard. Preserve null and original values.
- [x] Create `sql-desk/src/db.rs`: TLS connection, database/schema/table/column metadata, streaming SQL, deadlines and cancellation. Abort connection after incomplete protocol operations.
- [x] Create `sql-desk/src/main.rs`: callbacks and background worker; native file selection and disk work off UI thread.
- [x] Build release EXE and overwrite `sql-desk/SqlDesk.exe` after terminating existing instances. Review source for error paths, resource growth, stale results, and localization.

Review focus: empty results; multiple statements; cancel/timeout with transaction side effects; oversized rows/result storage; disconnected sessions and export failures. Real PostgreSQL/Redshift compatibility and long-duration memory/CPU require user testing.

Decisions: use installed GNU Rust + LLVM-MinGW because no MSVC linker/SDK is available. Desktop language follows OS locale until manually selected. Redshift uses password-based PostgreSQL protocol authentication; IAM/SSO is outside this version. SQL text capped at 2 MiB on import/execute; 32 result sets, 256 columns, 4 MiB encoded row, 512 MiB total spool. Preview budget 2 MiB; copy budget 8 MiB. Editor undo history resets across background operations to prevent accumulation across queries.

Review: independent read-only reviewer found unconditional disconnect on SQL errors and missing configuration write-size validation. Both corrected. One focused paging/export regression check added but not executed, per user rule. No app launch or database connection performed.

Final verification: release build succeeded; cargo fmt --check succeeded. `SqlDesk.exe`: 11,182,592 bytes. PE imports inspected: only Windows system libraries required.
